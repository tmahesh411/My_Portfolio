## Brand & Style

The design system establishes a focused, hyper-modern developer identity tailored for high-performance software engineering. The aesthetic merges precision engineering with refined minimalism: deep dark-space foundations, crisp micro-borders, and high-energy luminescent accents.

### Target Audience & Personality
- **Target Audience:** Engineering managers, CTOs, tech recruiters, and open-source collaborators seeking modern full-stack competence, code craftsmanship, and aesthetic rigor.
- **Personality:** Decisive, mathematically balanced, highly technical, and deliberate.
- **Emotional Response:** Confidence, cutting-edge precision, fluid modernity, and technical clarity without visual noise.

### Style Directives
- **Layered Obsidian Glass:** Surfaces rely on dark slate depths (`#090D16` to `#0F172A`) with micro-translucent fills, delicate borders, and targeted ambient neon illumination.
- **Code-First Architecture:** Monospaced data tags, key performance stats, and live telemetry indicators project algorithmic discipline.
- **Luminescent Accent Rhythm:** Vibrant cyan, electric blue, and emerald indicate system state, active projects, and live deployments.

## Colors

The palette is engineered around an ultra-dark canvas punctuated by radiant spectral accents. 

### Canvas & Surface Hierarchy
- **Canvas Base (`#090D16`):** The master canvas tone. High contrast against active data.
- **Surface Elevation 1 (`#0F172A`):** The primary container background for cards, project modules, and timeline rows.
- **Surface Elevation 2 (`#1E293B`):** Interactive hover states, elevated modals, and floating tech stacks.
- **Border Subtle (`rgba(255, 255, 255, 0.08)`): Base perimeter lines for panels.
- **Border Focus / Glow (`rgba(6, 182, 212, 0.35)`):** Emphasized borders on active focus or hover states.

### Core Accents
- **Primary — Cyan Spark (`#06B6D4`):** Represents interactive triggers, brand accents, primary CTAs, and active navigation nodes.
- **Secondary — Electric Cobalt (`#3B82F6`):** Applied across secondary CTAs, system linkages, and architecture diagrams.
- **Tertiary — Neon Emerald (`#10B981`):** Strictly reserved for system status, production deployment indicators, live preview links, and competitive coding accolades (e.g., LeetCode solved tags).

### Typography Tones
- **Text Primary (`#F8FAFC`):** Display headings and high-contrast labels.
- **Text Muted (`#94A3B8`):** Body paragraphs, contextual documentation, and dates.
- **Text Dim (`#64748B`):** Footers, inactive meta tags, and inactive icons.

## Typography

The typographic hierarchy pairs the contemporary geometric clarity of **Plus Jakarta Sans** with the monospaced utility of **JetBrains Mono**.

### Structural Strategy
- **Titles & Narrative:** Plus Jakarta Sans delivers sharp, modern authority with reduced tracking on larger sizes to prevent visually loose headings.
- **Technical Readouts & Metadata:** JetBrains Mono is used for technical specs, repository commits, build versions, skill badges, metrics, and dates. This distinguishes dynamic code elements from narrative copy.
- **Line Heights:** Generous line heights are maintained across `body-md` and `body-lg` to ensure effortless reading over dark surfaces.

## Layout & Spacing

The layout is built on a responsive 12-column fluid grid constrained by an ergonomic maximum container width of `1200px`.

### Responsive Breakpoints
- **Desktop (1024px+):** 12 columns, `margin: 4rem`, `gutter: 1.5rem`. Wide visual paths allow dual-column layouts for featured projects and multi-metric grids.
- **Tablet (768px - 1023px):** 8 columns, `margin: 2rem`, `gutter: 1.25rem`. Content stacks to split 50/50 blocks into modular horizontal units.
- **Mobile (0px - 767px):** 4 columns, `margin: 1.25rem`, `gutter: 1rem`. All multi-column cards collapse to single-column full-width stacks.

### Spacing Rhythm
- **Micro Spacing (`space-xs`, `space-sm`):** Reserved for chip internal padding, badge iconography alignment, and card header subtitles.
- **Macro Spacing (`space-md`, `space-lg`, `space-xl`):** Dedicated to container padding, card body offsets, grid gaps, and inter-section transitions.

## Elevation & Depth

Visual hierarchy uses a dark-stacking depth model relying on low-opacity borders, surface tonal shifts, and radial glow projections. Heavy drop shadows are avoided.

### Layer Architecture
- **Layer 0 (Canvas Base):** Solid `#090D16`. Background decorations feature subtle radial gradients centered on viewport focus areas (`rgba(6, 182, 212, 0.05)`).
- **Layer 1 (Modular Surfaces):** Solid `#0F172A` with a 1px border of `rgba(255, 255, 255, 0.06)`. 
- **Layer 2 (Floating & Hover States):** `#1E293B` backed by a neon-tinted ambient glow (`0px 10px 30px -10px rgba(6, 182, 212, 0.25)`).

### Glassmorphism Treatment
- Sticky headers, floating mobile navbars, and modal sheets utilize frosted glass with `backdrop-filter: blur(16px)` and background tint `rgba(9, 13, 22, 0.75)`.

## Shapes

The design system adopts a crisp, modern architectural contour (`roundedness: 1`). 

### Geometry Standards
- **Containers & Project Cards:** `rounded-lg` (8px / 0.5rem) ensures an engineered, dashboard-like silhouette.
- **Interactive Badges & Tech Chips:** `rounded` (4px / 0.25rem) keeps code tags compact.
- **Status Pills & Live Indicators:** Fully circular (9999px) strictly for pulse indicators, live preview tags, and social icon rings.

## Components

### Buttons
- **Primary Action (Cyan Glow):** Solid `#06B6D4` background, `#090D16` high-contrast bold typography (`Plus Jakarta Sans`, 600 weight). Hover activates a subtle `0px 0px 20px rgba(6, 182, 212, 0.5)` drop glow.
- **Secondary Action (Ghost Frame):** Background transparent, 1px border `rgba(255, 255, 255, 0.15)`, text `#F8FAFC`. Hover applies background `rgba(255, 255, 255, 0.05)` and border `#3B82F6`.
- **Icon / Direct Link Buttons:** Compact square or rounded 40px buttons for GitHub, LinkedIn, and LeetCode, featuring 1px border and hover fill matching each platform's accent.

### Chips & Badges
- **Tech Stack Tag:** JetBrains Mono, `label-code-sm`, padding `space-xs` horizontal `space-sm`. Background `rgba(15, 23, 42, 0.8)`, border `rgba(255, 255, 255, 0.08)`, text `#94A3B8`.
- **Live Preview Badge:** Emerald status pill. Background `rgba(16, 185, 129, 0.1)`, border `rgba(16, 185, 129, 0.3)`, text `#10B981`. Includes a pulsing 6px emerald status dot.

### Project & Showcase Cards
- **Card Body:** Background `#0F172A`, 1px border `rgba(255, 255, 255, 0.07)`, padding `space-lg`.
- **Hover Transition:** Smooth translateY(-4px) alongside a border color shift to `rgba(6, 182, 212, 0.4)` and a localized top-edge accent highlight.

### Timeline (Education & Milestones)
- **Track & Node:** 2px vertical rail in `rgba(255, 255, 255, 0.08)`. Nodes are hollow circles (`#090D16`) with an active `#06B6D4` or `#3B82F6` center.
- **Content Blocks:** Right-aligned or stacked chronological cards highlighting degree, institution, and core coursework in JetBrains Mono.

### Form Inputs (Contact)
- **Input & Textarea:** Background `#090D16`, border 1px `rgba(255, 255, 255, 0.12)`, text `#F8FAFC`, placeholder `#64748B`. Focused state introduces border color `#06B6D4` with an inner halo of `0 0 0 1px #06B6D4`.
